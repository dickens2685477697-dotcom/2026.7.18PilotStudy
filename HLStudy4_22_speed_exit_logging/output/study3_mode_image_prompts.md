# Study3 mode selected 图示生成提示词

本文档根据 Study3 源码中的 `modeSelected` 定义和行为分支整理。  
主要依据：

- `Assets/Scripts/Study3/BallSpawner.cs`：`Mode` 枚举与 Inspector 显示名称。
- `Assets/Scripts/Study3/S2AccMode.cs`：各 mode 的触发、取消、退出逻辑。
- `Assets/Scripts/Study3/ReleaseGesture.cs`：Release 手势检测逻辑。

通用视觉约束：所有图片建议使用同一风格：白色或浅灰背景、半透明 3D 右手、半透明目标球、清晰箭头、少量中文标签。绿色表示触发/成功选择，红色或橙色表示取消，灰色圆环表示“准备状态/ready ring”。不要生成代码、水印、复杂背景或多余文字。
